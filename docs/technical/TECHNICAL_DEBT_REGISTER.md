# Registro de débito técnico

## Uso do registro

Este inventário consolida follow-ups já documentados. Prioridade é uma recomendação técnica para
triagem, não aprovação de escopo. Itens dependentes de decisão humana não devem ser implementados
apenas por constarem aqui.

## Critério de encerramento

Um item só é encerrado com mudança integrada, validação correspondente e atualização explícita
deste registro. Merge de branch paralela, aprovação parcial ou teste apenas local não encerra
automaticamente dívida relacionada a produção.
